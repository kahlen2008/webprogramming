Student Profile Editor

A complete form for a student management system, built with controlled React inputs. Every field is required: the student ID must be exactly 10 digits and the bio has a live character counter capped at 200. Validation runs on every keystroke but only shows once you leave a field or press Save. A valid submit renders the ProfilePreview card, and skills can be added as tags with Enter and removed with ×.

Live Profile Editor

Fill in the form and press Save profile. Try an 8-digit ID or a 201-character bio to see the validation.
