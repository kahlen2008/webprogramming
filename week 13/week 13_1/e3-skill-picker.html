Skill Picker with Limit

Task Specification: Show a list of 6 programming skills as checkboxes. Display a live counter of selected skills. If more than 3 are selected, show a warning: "Please select at most 3 skills."

Key Takeaways

  • Array state for checkboxes: selected holds the checked skill names, and each box is controlled with checked={selected.includes(skill)}.
  • Add or remove immutably: checking spreads into a new array, unchecking uses filter. Neither mutates the old array, so React sees a new value and re-renders.
  • Derived counter and warning: selected.length and selected.length > 3 are calculated during render, not stored, so they always match the checkboxes.
  • Warn, don’t block: as the task asks, a 4th box can still be checked; the warning appears until you uncheck back down to 3.
