React Contact Form on My Portfolio

The “implement the relevant React element within personal pages” part of this week’s homework. I rebuilt the contact form on my digital portfolio as a React component: it validates name, email and message on submit, shows each error under its field, and after sending it says “Thank you, {name}!” and resets the form.

Where It Lives

The contact page of my portfolio site, in the kahlensdigitalportfolio repository.

contact.html

Live at https://kahlen2008.github.io/kahlensdigitalportfolio/contact.html

Open my contact page

Vanilla JS → React component

The old script.js handler that toggled CSS classes on the DOM is gone. ContactForm now keeps the fields in one form state object and renders from it.

Validation with messages under each field

Name, email and message are all checked on submit, and the email must match a pattern. Each error shows directly under its field and clears as soon as you type there.

“Thank you, {name}!” and reset

After Formspree accepts the message, the form shows a personal thank-you in place of the old pop-up, and the fields reset. “Send another message” brings the form back.

Same look, same Formspree inbox

The component reuses the site’s existing .form-group, .error-message and button styles, and still posts to the same Formspree endpoint. If JavaScript is off, the original HTML form still works as a fallback.
