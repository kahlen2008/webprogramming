Bio Field with Live Count

Task Specification: Build a controlled <textarea> with a maximum of 200 characters. Show a live character count (X / 200) below it. Disable the textarea when the limit is reached.

Key Takeaways

  • Controlled textarea: value={bio} plus onChange means React state is the single source of truth, so the counter can never drift from what is in the box.
  • .slice(0, MAX) in onChange: a long paste is cut at 200 instead of overflowing. The count is just bio.length, derived on every render, not stored separately.
  • disabled={bio.length >= MAX}: the textarea locks at the limit, exactly as the task asks.
  • The catch: a disabled textarea can’t be edited at all, not even to delete text. So the demo adds “Delete last character” and “Delete last word” buttons that update the state and unlock the box again.
