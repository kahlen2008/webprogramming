UX Evaluation & Question UX Analysis
✕ Question: Is this a good user experience?

No. The default 404 completely strips the user away from the site's layout. It looks like the entire server crashed or the project was deleted. There are no navigation links, no search bar, and no way back to safety other than the browser's back button.

✓ What would you improve?

1. Maintain Visual Identity: Keep the dark aesthetic, font family, and header.
2. Clear Guidance: Provide friendly, non-technical explanations.
3. Clear Recovery Links: Direct buttons to Homepage, Coursework Index, and a "Go Back" action.

💡 GitHub Pages Automatic 404 Mechanism

GitHub Pages automatically serves 404.html whenever an invalid or deleted route is requested — provided that file exists at the root of your publishing branch. When the file is present, GitHub returns HTTP 404 status code while rendering your custom HTML, keeping visitors inside your brand and navigation hierarchy!
