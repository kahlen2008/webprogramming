Remote Repositories

Push Your Repo to GitHub

Link your local Git repository to a GitHub remote URL using origin tracking, set the upstream default branch, and push committed changes.

Remote Configuration & Push Workflow bash
# 1. Add GitHub remote tracking origin
$ git remote add origin https://github.com/kahlen2008/kahlensdigitalportfolio.git
# 2. Rename default branch to standard 'main'
$ git branch -M main
# 3. Push commit snapshots to GitHub and set upstream
$ git push -u origin main

Remote Management Essentials

  • ✓ git remote add origin <url> binds a friendly alias (origin) to the cloud repository URL.
  • ✓ git branch -M main sets the primary branch name to main following modern conventions.
  • ✓ git push -u origin main pushes commits to the remote and establishes tracking so subsequent pushes only need git push.
  • ✓ Remote pushes back up local history and enable deployment via GitHub Pages.
