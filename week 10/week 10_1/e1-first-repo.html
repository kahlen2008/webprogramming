Git Fundamentals

Create Your First Repository

Initialize a local Git repository, create a project entrypoint file, inspect file tracking status, stage modifications, and record an initial root commit.

Git Bash / Terminal Command Sequence bash
# 1. Create a new project folder and enter it
$ mkdir my-first-git && cd my-first-git
# 2. Initialize Git (creates hidden .git directory)
$ git init
Initialized empty Git repository in .../my-first-git/.git/
# 3. Create a simple HTML file
$ echo "<h1>Hello Git</h1>" > index.html
# 4. Check status — index.html is Untracked
$ git status
Untracked files:
  (use "git add <file>..." to include in what will be committed)
    index.html
# 5. Stage the file into the Git index
$ git add index.html
# 6. Commit with a meaningful, descriptive message
$ git commit -m "feat: initial portfolio website structure and assets"
[main (root-commit) e5419f7] feat: initial portfolio website structure and assets
 1 file changed, 1 insertion(+)
# 7. View one-line history log
$ git log --oneline
e5419f7 feat: initial portfolio website structure and assets

Key Points & Git Mechanics

  • ✓ git init creates the hidden .git database where Git tracks commits, trees, and branches.
  • ✓ git status reveals which files are untracked, modified, or staged in the staging area.
  • ✓ git add moves files into the staging index, preparing them to be recorded in the next snapshot.
  • ✓ git commit -m "message" creates a permanent cryptographic SHA snapshot with author metadata.
