Open-Meteo API

Current weather comes from api.open-meteo.com/v1/forecast, which is free and needs no API key.

Input

Search by city name through the geocoding endpoint (up to 5 matches to choose from), or enter latitude and longitude with range checks.

Display

Current temperature, wind speed and a weather description mapped from the WMO weather code, plus feels-like, humidity and wind direction.

useEffect fetch

The effect depends on latitude and longitude, so it runs again whenever they change. It sets a loading state and aborts the previous request in its cleanup.

Error handling

Separate messages for network down (with automatic retry when you come back online), bad coordinates (HTTP 400), rate limit (HTTP 429), timeouts and other server errors. Use the test buttons to see each one.

Bonus: geolocation

navigator.geolocation behind a “Use my location” button. If you already granted permission, the page detects your location on load without asking again.
