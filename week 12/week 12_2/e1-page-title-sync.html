Page Title Sync

Task Specification: Build a component with a text input. Use useEffect to update document.title to show whatever is typed in the input. Revert the title to "WebPro" when the component unmounts (via cleanup).

TitleEditor.jsx React + Vite 
import { useState, useEffect } from 'react';

function TitleEditor() {
  const [text, setText] = useState('');

  useEffect(() => {
    document.title = text || 'WebPro';
    return () => { document.title = 'WebPro'; }; // cleanup on unmount
  }, [text]);

  return (
    <input
      value={text}
      onChange={e => setText(e.target.value)}
      placeholder="Type to change tab title…"
    />
  );
}

export default TitleEditor;

Key Takeaways

  • document.title is a side effect: it changes something outside React's own output, so it belongs in useEffect, which runs after React has updated the screen.
  • [text] dependency: the effect re-runs only when text changes, so every keystroke updates the title and nothing else triggers it.
  • text || 'WebPro': an empty string is falsy, so clearing the input shows WebPro instead of a blank tab.
  • When cleanup runs: React calls the returned function before each re-run (the new effect then sets the title straight away) and once more on unmount, which is what leaves the title as WebPro when the component is gone.
