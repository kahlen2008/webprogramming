Show & Hide Details

Task Specification: Build a component with a button labeled Show details / Hide details. When clicked, toggle the visibility of a paragraph of text using boolean state.

Live Demo

isVisible: false

React state enables dynamic UIs without page reloads.

ToggleDetail.jsx React + Vite 
import { useState } from 'react';

function ToggleDetail() {
  const [isVisible, setIsVisible] = useState(false);

  return (
    <div>
      <button onClick={() => setIsVisible(prev => !prev)}>
        {isVisible ? 'Hide details' : 'Show details'}
      </button>
      {isVisible && (
        <p>React state enables dynamic UIs without page reloads.</p>
      )}
    </div>
  );
}

export default ToggleDetail;

Key Takeaways

  • Boolean state: useState(false) stores a single true/false flag. The details start hidden.
  • Flip with the previous value: setIsVisible(prev => !prev) always toggles from the latest state, even if clicks happen quickly.
  • Conditional rendering with &&: {isVisible && <p>…</p>} only puts the paragraph in the DOM when isVisible is true.
  • Ternary for the label: isVisible ? 'Hide details' : 'Show details' picks the button text from the same state, so it never gets out of sync.
