Counter with History & Undo

Task Specification: Build a Counter component using two state variables: count and history (an array). Every time the count changes, push the new value into history and keep only the last 5. Undo sets the count to history[history.length - 2] and removes the last item from history.

import { useState } from 'react';

function Counter() {
  // Two state variables: the current value + the last 5 values
  const [count, setCount] = useState(0);
  const [history, setHistory] = useState([0]);

  // Every change goes through here, so history always matches count
  const changeCount = (newCount) => {
    if (newCount === count) return; // e.g. Reset while already 0
    setCount(newCount);
    setHistory(prev => [...prev, newCount].slice(-5)); // keep last 5
  };

  const undo = () => {
    if (history.length < 2) return; // nothing to go back to
    setCount(history[history.length - 2]);
    setHistory(prev => prev.slice(0, -1)); // remove last item
  };

  return (
    <div className="counter">
      <h2>Count: {count}</h2>

      <button onClick={() => changeCount(count - 1)}>-1</button>
      <button onClick={() => changeCount(count + 1)}>+1</button>
      <button onClick={() => changeCount(0)}>Reset</button>
      <button onClick={undo} disabled={history.length < 2}>Undo</button>

      <p>History: [{history.join(', ')}]</p>
    </div>
  );
}

export default Counter;

Key Takeaways

  • History starts as [0]: the starting count is the first entry, so the very first +1 gives [0, 1] and Undo has somewhere to go back to.
  • Immutable updates: [...prev, newCount] and slice() build a new array. Calling push() or pop() on state changes the old array in place, and React may not re-render.
  • slice(-5) keeps the last 5: a negative start index counts from the end, so the oldest value drops off once there are more than 5.
  • Undo = second-to-last item: the last item in history is the current count, so the previous value is history[history.length - 2]. Undo is disabled when only one value is left.
