Add & Remove Tasks

Task Specification: Build a component with a text input and an Add button. Items typed in the input are added to an array stored in state. Each item has a ✕ button that removes it from the list.

    TaskList.jsx React + Vite 
    import { useState } from 'react';

function TaskList() {
  const [tasks, setTasks] = useState([]);
  const [input, setInput] = useState('');

  function addTask() {
    if (!input.trim()) return;
    setTasks(prev => [...prev, { id: Date.now(), text: input.trim() }]);
    setInput('');
  }

  function removeTask(id) {
    setTasks(prev => prev.filter(t => t.id !== id));
  }

  return (
    <div>
      <input value={input} onChange={e => setInput(e.target.value)}
        onKeyDown={e => e.key === 'Enter' && addTask()} // Enter also adds
        placeholder="New task" />
      <button onClick={addTask}>Add</button>
      <ul>
        {tasks.map(task => (
          <li key={task.id}>
            {task.text}
            <button onClick={() => removeTask(task.id)}>✕</button>
          </li>
        ))}
      </ul>
    </div>
  );
}

export default TaskList;

    Key Takeaways

    • Controlled input: value={input} plus onChange keeps the text box and the input state in sync, so setInput('') clears it after adding.
    • Enter to add: onKeyDown checks e.key === 'Enter' and calls the same addTask as the button, so both ways follow the same rules.
    • Add with spread: [...prev, newTask] creates a new array with the task on the end. Blank input is ignored by the trim() check.
    • Remove with filter: prev.filter(t => t.id !== id) returns a new array without that task. The original array is never changed.
    • Stable keys: each task gets an id from Date.now(), used as key so React can tell the items apart when one is removed.
