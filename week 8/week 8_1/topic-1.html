Why Forms? — Google Search Form

<form action method>

Forms are the primary way users send data to a server. The Google search bar is a classic single-field HTML form with method="get":

HTML 
<!-- The Google search bar is just an HTML form -->
<form action="https://www.google.com/search" method="get">
  <input type="text" name="q" placeholder="Search Google...">
  <button type="submit">Search</button>
</form>
Interactive Output Live & Functional
✓ Try it: Submitting will send the query string parameter ?q=... to Google in a new tab.
