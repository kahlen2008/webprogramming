checkValidity()

Constraint Checking

checkValidity() is a browser built-in method that programmatically evaluates all HTML5 validation rules. Call it on an individual input to check just that field, or on the whole form to check every field at once.

JavaScript 
const emailInput = document.querySelector('#email');
const form = document.querySelector('#my-form');

// Check a single field
if (!emailInput.checkValidity()) {
  console.log('Email is invalid');
  console.log(emailInput.validity.valid);        // false
  console.log(emailInput.validity.valueMissing); // true if empty + required
  console.log(emailInput.validity.typeMismatch); // true if bad email format
}

// Check the entire form (returns false if ANY field is invalid)
if (!form.checkValidity()) {
  console.log('Form has errors');
}

// The .validity property is always there — no need to call checkValidity() first
console.log(emailInput.validity.valid);  // true or false right now

Key Points
  • input.checkValidity() returns a clean boolean (true or false).
  • input.validity is a ValidityState object containing detailed boolean flags.
  • input.validity.valid gives a quick check: is the entire input valid right now?
  • form.checkValidity() checks ALL fields in the form and returns false if even one is invalid.
  • Calling checkValidity() does NOT display any browser UI or tooltips — it only returns a boolean.
