The validity Object

ValidityState Inspector

Every form input element has a validity property — a read-only ValidityState object with boolean properties that explain exactly why an input is invalid. Use this to construct specific, helpful custom error messages.

JavaScript 
function getError(input) {
  const v = input.validity;

  if (v.valueMissing)    return 'This field is required.';
  if (v.typeMismatch)    return 'Please enter a valid email address.';
  if (v.tooShort)        return `Minimum \${input.minLength} characters.`;
  if (v.patternMismatch) return input.title || 'Invalid format.';
  if (v.rangeUnderflow)  return `Minimum value is \${input.min}.`;
  if (v.rangeOverflow)   return `Maximum value is \${input.max}.`;
  return '';
}

Key Points
  • validity.valid is true only when ALL error flags (valueMissing, typeMismatch, etc.) are false.
  • Inspect specific flags to provide targeted error instructions instead of a generic "Invalid value" label.
  • Template literals (e.g. `Minimum ${input.minLength} characters.`) allow dynamic messages reflecting actual HTML constraint values.
  • validity.customError turns true whenever setCustomValidity('...') is invoked with a non-empty string.
