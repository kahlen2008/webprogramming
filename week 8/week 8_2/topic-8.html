Password Confirmation

Multi-Field Synchronization

Comparing two fields is a classic JavaScript task that HTML5 cannot perform alone. The pattern listens on the confirm field's 'input' event, compares values, re-checks when the primary password changes, and sets custom validity.

JavaScript 
const pw     = document.querySelector('#password');
const confirm = document.querySelector('#confirm');
const pwErr   = document.querySelector('#pw-error');
const cfmErr  = document.querySelector('#cfm-error');

// Validate password length & re-check confirm if typed
pw.addEventListener('input', () => {
  if (pw.value.length < 8) {
    pwErr.textContent = 'Password must be at least 8 characters.';
  } else {
    pwErr.textContent = '';
  }
  if (confirm.value) checkConfirm();
});

function checkConfirm() {
  if (confirm.value !== pw.value) {
    confirm.setCustomValidity('Passwords do not match.');
    cfmErr.textContent = 'Passwords do not match.';
  } else {
    confirm.setCustomValidity('');
    cfmErr.textContent = '';
  }
}

confirm.addEventListener('input', checkConfirm);

Key Points
  • Always listen on the confirm field AND re-validate when the original password field changes.
  • Synchronize setCustomValidity('...') so native form submission stops the user with browser tooltips.
  • Always display clear in-page visual error text in your own UI element, not just the temporary browser popup.
  • Clear the custom error with setCustomValidity('') as soon as strings match.
