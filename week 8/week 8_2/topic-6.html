Real-time Feedback with the "input" Event

Live Keystroke UX

The 'input' event fires on every keystroke as the field's value changes. Combined with a function checking validity, this provides instantaneous visual feedback, dynamic green/red border states, and instant error removal.

JavaScript 
const emailInput = document.querySelector('#email');
const emailError = document.querySelector('#email-error');

emailInput.addEventListener('input', () => {
  const v = emailInput.validity;

  if (v.valid) {
    emailError.textContent = '';          // clear error
    emailInput.classList.remove('error');
    emailInput.classList.add('ok');
  } else {
    if (v.valueMissing) emailError.textContent = 'Email is required.';
    if (v.typeMismatch) emailError.textContent = 'Not a valid email format.';
    emailInput.classList.add('error');
    emailInput.classList.remove('ok');
  }
});

Key Points
  • 'input' fires immediately on every keystroke — use it for dynamic, responsive feedback.
  • 'change' fires only when focus leaves the field (blur) — better for slower, less aggressive checks.
  • Only show error highlights after the user has started interacting with the field; don't flash empty inputs red immediately.
  • Standard pattern: read input.validity → update error span text → toggle .ok / .error classes.
