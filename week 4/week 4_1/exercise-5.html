Interactive Colour Palette

Interactions

  • Click a colour box to expand it and reveal its hex code.
  • Double-click a colour box to remove it from the palette.
  • Add Colour — type a hex code (e.g. #ff5733) and press "Add Colour" to create a new box.
  • Export PNG — downloads the current palette as an image file.

How localStorage Works Here

  • Every time you add or remove a colour, the current list of hex codes is saved using localStorage.setItem().
  • When the page reloads, the saved list is retrieved with localStorage.getItem() and the boxes are restored automatically.
  • This means your palette persists across page reloads — try adding a colour, refreshing, and it will still be there!
