E3: Add defer to Scripts — Before & After

Script Loading & CRP

Fix script loading order by placing scripts in <head> with defer and async. defer downloads scripts in parallel during HTML parsing and executes in source order once the DOM is constructed.

HTML (Optimized Solution) 
<head>
  <meta charset="UTF-8">
  <title>Script Loading Demo</title>

  <!-- FIX 1: Non-blocking independent analytics script -->
  <script async src="analytics.js"></script>

  <!-- FIX 2: App script in <head> with defer (guarantees DOM ready) -->
  <script defer>
    // This script modifies the DOM — defer guarantees DOM ready state
    document.getElementById('status').textContent =
      '✅ DOM was ready when this script ran (add defer to verify)';
    document.getElementById('status').className = 'status ok';
  </script>
</head>

<body>
  <h2>Script Loading Test</h2>
  <p>With defer, the DOM is ready when scripts run.</p>
  <div id="status" class="pending">Waiting for script...</div>
</body>

Core Optimization Rules
  • defer scripts download in the background without halting the HTML parser.
  • defer scripts always execute in document order right before DOMContentLoaded.
  • async is ideal for independent third-party scripts like analytics that do not touch the DOM.
