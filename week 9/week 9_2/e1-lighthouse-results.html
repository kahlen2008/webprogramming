Performance Optimization

Run a Lighthouse Performance audit to identify render-blocking script pauses and missing dimensions. Adding defer to scripts prevents parser stall, explicit width and height eliminate layout shifts (CLS), and loading="lazy" defers offscreen images.

Core Optimization Rules
  • Adding defer to scripts prevents parser blocking during initial HTML document compilation.
  • Setting explicit width="1200" and height="800" reserves the aspect ratio in CSS beforehand to prevent Cumulative Layout Shift (CLS).
  • loading="lazy" prevents offscreen images from competing for network bandwidth with the hero LCP element.
