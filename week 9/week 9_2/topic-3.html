03 · Minification

Assets

Minification removes all whitespace, comments, and unnecessary characters from CSS and JavaScript files without changing how they work. The result is a smaller file that loads and parses faster.

CSS — Before and After Minification 
/* BEFORE (readable, 287 bytes) */
.nav {
  display: flex;
  align-items: center;
  background-color: #1a2340;
  padding: 12px 24px;
}

.nav a {
  color: #ffffff;
  text-decoration: none;
  font-weight: 600;
}

/* AFTER MINIFICATION (108 bytes, 62% smaller) */
.nav{display:flex;align-items:center;background-color:#1a2340;padding:12px 24px}.nav a{color:#fff;text-decoration:none;font-weight:600}

Key Points
  • Minification removes whitespace, comments, and shortens identifiers — typically 40–70% smaller.
  • Use file.min.css and file.min.js naming convention for minified production bundles.
  • Modern build tools (Vite, webpack, Parcel) minify automatically in production mode.
  • Combined with gzip/Brotli compression from the web server, assets can be 80–90% smaller than original sources.
