01 · Image Optimization

Assets

Images are typically the largest files on any web page — often 60–80% of total page weight. Optimizing images has the highest impact on performance of any single change you can make.

HTML — Responsive images with srcset 
<!-- Basic WebP with JPEG fallback -->
<picture>
  <source srcset="hero.webp" type="image/webp">
  <img src="hero.jpg" alt="Campus at sunrise" width="1200" height="600">
</picture>

<!-- Responsive srcset: browser picks the right size -->
<img
  src="photo-800.jpg"
  srcset="photo-400.jpg 400w,
          photo-800.jpg 800w,
          photo-1200.jpg 1200w"
  sizes="(max-width:600px) 100vw, 800px"
  alt="Description of image"
  width="800" height="400">

<!-- Always specify width and height to prevent CLS -->
<img src="photo.jpg" alt="..." width="800" height="400">

Key Points
  • Images are usually 60–80% of page weight — optimize these first for maximum performance ROI.
  • WebP is the best choice for most web images — 25–34% smaller than JPEG, supported by all modern browsers.
  • Use srcset and sizes to serve the right image size for each screen resolution.
  • Always add width and height attributes on <img> to prevent layout shift (CLS).
  • Use <picture> with a WebP source and JPEG fallback for maximum compatibility across all devices.
