E2: Compare Image Formats (WebP vs JPEG)

Responsive & Modern Formats

Wrap images in <picture> with a WebP <source> and a JPEG <img> fallback. Use srcset with 400w and 800w variants, explicit width/height attributes, and fetchpriority="high" for above-the-fold hero rendering.

HTML (Optimized Solution) 
<!-- <picture> with WebP source + JPEG fallback -->
<picture>
  <!-- Next-gen WebP with responsive srcset (400w / 800w) -->
  <source 
    type="image/webp"
    srcset="photo-400.webp 400w, photo-800.webp 800w"
    sizes="(max-width: 480px) 400px, 800px">

  <!-- Backward-compatible JPEG fallback with dimensions -->
  <img 
    src="photo-800.jpg" 
    srcset="photo-400.jpg 400w, photo-800.jpg 800w" 
    sizes="(max-width: 480px) 400px, 800px" 
    alt="Scenic nature landscape at sunrise" 
    width="800" height="400" fetchpriority="high">
</picture>

<p style="margin-top:12px;font-size:13px;color:#666">
  WebP files achieve 25-34% smaller file sizes vs JPEG at identical visual quality.

Core Optimization Rules
  • The <picture> element evaluates <source> tags from top to bottom, falling back to <img> if unsupported.
  • srcset with w descriptors allows the browser to select the ideal resolution without downloading both files.
  • fetchpriority="high" prioritizes the hero image in the preload queue to boost Largest Contentful Paint (LCP).
