Semantic HTML

<header> <nav> <main> <footer>

Semantic HTML means using elements that describe their meaning — not just their visual appearance. A screen reader doesn't see CSS; it reads the HTML structure and announces what each element is. Semantic elements give assistive technologies a map to jump directly between landmarks.

HTML Comparison 
<!-- ✅ Semantic HTML — meaningful structure -->
<header>
  <a href="/">My Site</a>
  <nav aria-label="Main navigation">
    <a href="/">Home</a>
    <a href="/about">About</a>
  </nav>
</header>
<main>
  <article>
    <h1>Hello</h1>
    <p>World</p>
  </article>
</main>
<footer>© 2026</footer>
