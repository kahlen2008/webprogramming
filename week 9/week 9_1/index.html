Web Accessibility & Lighthouse

Interactive exercises and core lecture topics covering semantic HTML, button accessibility, alt text guidelines, ARIA attributes, and keyboard navigation.

Lecture Topics (Core Concepts & Interactive Demos)
  • 01
    Semantic HTML Meaning over visual appearance, landmark navigation, header/nav/main/footer, and heading hierarchy.
  • 02
    The <button> vs <div> Problem Why div onclick breaks keyboard Tab/Enter/Space, ARIA roles, and native button benefits.
  • 03
    alt Text Deep Dive Decision tree for decorative (alt=""), informational, linked logos, and complex charts with captions.
  • 04
    ARIA Attributes First rule of ARIA, aria-label, aria-describedby, aria-hidden, aria-live, and role="alert".
  • 05
    Keyboard Navigation WCAG 2.1.1 requirements, Tab/Enter/Space, :focus-visible outlines, tabindex, and skip links.
Practice Exercises
  • E1
    Fix a div-button to a real <button> Replace outer <div class="btn"> with <button type="button">, add visible :focus-visible style, and test keyboard accessibility.
  • E2
    Add Proper alt Text to Images Configure alt descriptions across 4 scenarios: informative campus photo, decorative wave divider, linked logo, and data chart.
  • E3
    Run Lighthouse & Fix 2 Issues Resolve audit failures: add accessible name to icon button, pair input with explicit <label>, provide text marker for errors, and fix generic link alt text.
