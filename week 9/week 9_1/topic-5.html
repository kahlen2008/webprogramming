Keyboard Navigation

WCAG 2.1.1 (Level A)

Many users cannot use a mouse — they navigate with keyboard devices alone. Your entire website must be fully usable with just Tab, Shift+Tab, Enter, Space, and arrow keys.

CSS & HTML Patterns 
/* ✅ :focus-visible — shows focus ring for keyboard, not mouse clicks */
:focus-visible {
  outline: 3px solid #1a7f5a;
  outline-offset: 3px;
  border-radius: 4px;
}

/* ❌ Never do this — removes focus for keyboard users! */
*:focus { outline: none; }

<!-- tabindex="0" — adds element to natural tab order -->
<div role="button" tabindex="0">Custom widget</div>

<!-- Skip navigation link -->
<a href="#main" class="skip-link">Skip to content</a>
