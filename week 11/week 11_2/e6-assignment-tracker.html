Track Assignment Progress

Task Specification: Store tasks as objects with an id, text, and done flag. Ticking a checkbox updates just that object with map. Add All / Active / Done filter buttons and a Clear completed button that removes finished tasks.

Live Demo

    No tasks match this filter.

    AssignmentTracker.jsx React + Vite 
    import { useState } from 'react';

const starterTasks = [
  { id: 1, text: 'Re-read the props notes', done: true },
  { id: 2, text: 'Finish the counter exercise', done: false },
  { id: 3, text: 'Submit the lab checklist', done: false },
];

function AssignmentTracker() {
  const [tasks, setTasks] = useState(starterTasks);
  const [filter, setFilter] = useState('all');

  function toggleTask(id) {
    setTasks(prev => prev.map(task =>
      task.id === id ? { ...task, done: !task.done } : task
    ));
  }

  const clearCompleted = () => setTasks(prev => prev.filter(t => !t.done));

  const visible = tasks.filter(task =>
    filter === 'active' ? !task.done :
    filter === 'done'   ?  task.done : true
  );

  return (
    <div>
      {['all', 'active', 'done'].map(f => (
        <button key={f} aria-pressed={filter === f} onClick={() => setFilter(f)}>
          {f}
        </button>
      ))}

      <ul>
        {visible.map(task => (
          <li key={task.id}>
            <label>
              <input type="checkbox" checked={task.done} onChange={() => toggleTask(task.id)} />
              {task.text}
            </label>
          </li>
        ))}
      </ul>

      <button onClick={clearCompleted}>Clear completed</button>
    </div>
  );
}

export default AssignmentTracker;

    Key Takeaways

    • Updating one object: map returns a new array; the matching task is copied with { ...task, done: !task.done } and the rest are returned unchanged.
    • Derived list: visible is calculated from tasks and filter on every render instead of being stored as a second copy in state.
    • Clearing: filter(t => !t.done) keeps only unfinished tasks, again without touching the original array.
