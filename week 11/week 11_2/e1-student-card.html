StudentCard: Fill in the Blanks

Task Specification: Create a React project with Vite, then fill in the blanks to complete the StudentCard component so it displays the name, id, and major props it receives. It should work when used as <StudentCard name="Kahlen Ong" id="20269947" major="Computer Engineering" />.

Project Setup

Terminal Vite + React 
$ npm create vite@latest my-app -- --template react
$ cd my-app
$ npm install
$ npm run dev

Live Rendered Component

StudentCard.jsx Answers highlighted 
// Definition: destructure the three props in the parameter list
function StudentCard({ name, id, major }) {
  return (
    <div className="card">
      <h2>{name}</h2>
      <p>ID: {id}</p>
      <p>Major: {major}</p>
    </div>
  );
}

// Usage in App:
<StudentCard
  name="Kahlen Ong"
  id="20269947"
  major="Computer Engineering"
/>

Key Takeaways

  • Blank 1 — { name, id, major }: React collects every attribute on <StudentCard /> into one props object. Destructuring pulls the three values out by name.
  • Blanks 2–4 — name, id, major: curly braces in JSX switch back to JavaScript, so each variable's value is printed into the card.
  • Without destructuring: function StudentCard(props) works the same way, using {props.name}, {props.id}, and {props.major}.
