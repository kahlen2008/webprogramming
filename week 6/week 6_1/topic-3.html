HTML5 Input Types

type attribute controls

The type attribute tells the browser what kind of data to expect, adapting mobile virtual keyboards and built-in controls:

HTML 
<input type="text"     placeholder="Any text">
<input type="email"    placeholder="name@email.com">
<input type="password" placeholder="Secret...">
<input type="number"   min="1" max="10">
<input type="date">
<input type="range"    min="0" max="100">
<input type="checkbox" name="agree">
<input type="radio"    name="gender" value="m">

<select name="major">
  <option value="">-- Select --</option>
  <option value="cs">Computer Science</option>
</select>
