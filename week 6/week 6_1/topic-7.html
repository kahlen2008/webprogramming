CSS Validation Pseudo-classes

:valid · :invalid · :not(:placeholder-shown)

CSS matches inputs dynamically based on their validation state without requiring JavaScript event listeners:

CSS 
/* :focus — keyboard focus ring */
input:focus {
  border-color: #1a56db;
  box-shadow: 0 0 0 3px rgba(26, 86, 219, 0.2);
  outline: none;
}

/* :valid — passes validation */
input:valid {
  border-color: #16a34a;
}

/* :invalid — fails validation */
input:invalid {
  border-color: #dc2626;
}

/* Combined with :placeholder-shown */
input:invalid:not(:placeholder-shown) {
  border-color: #dc2626;
  background: #fee2e2;
}

input:valid:not(:placeholder-shown) {
  border-color: #16a34a;
  background: #dcfce7;
}

Stays neutral until typing begins, then turns green or red!
