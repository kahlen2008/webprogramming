setCustomValidity()

Custom Tooltip Messages

setCustomValidity(message) attaches a custom error string to an input element, immediately marking it as invalid regardless of its value. Passing an empty string '' clears the error and restores natural validity.

JavaScript 
const passwordInput = document.querySelector('#password');
const confirmInput  = document.querySelector('#confirm');

confirmInput.addEventListener('input', () => {
  if (confirmInput.value !== passwordInput.value) {
    // Mark the field as invalid with a custom message
    confirmInput.setCustomValidity('Passwords do not match.');
  } else {
    // Clear the custom error (field becomes valid again)
    confirmInput.setCustomValidity('');
  }
});

// After setCustomValidity('...'), validity.customError is true
// and validity.valid is false — until you clear it with ''
Live Demo — Tooltip & ValidityState Type to test
› confirmInput.validationMessage: ""
› validity.customError: false
› validity.valid: false (empty field)
⚠️
Always clear it! If you set a custom validity message and the user later fixes the input, you must call setCustomValidity(''). Otherwise, the field stays invalid forever!
Key Points
  • input.setCustomValidity('message') marks the field as invalid and sets the native browser tooltip message.
  • input.setCustomValidity('') clears the custom error, allowing the field to return to natural validity.
  • When custom validity is set, validity.customError is true and validity.valid is false.
  • The browser displays this custom message inside its native pop-up bubble upon form submission.
