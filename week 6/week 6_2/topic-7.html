Regex Patterns in JavaScript

RegExp Syntax & test()

Regular expressions describe string search patterns. In JavaScript, create them with literal /pattern/flags syntax and call regex.test(string) to return true or false. Regex in JS allows logical OR, lookaheads, and combined checks.

JavaScript 
// Korean student ID: exactly 9 digits
const studentIdRegex = /^\d{9}$/;
studentIdRegex.test('202112345');   // true
studentIdRegex.test('20211234');    // false (8 digits)
studentIdRegex.test('2021abc12');   // false (letters)

// Email pattern
const emailRegex = /^[^\s@]+@[^\s@]+\.[^\s@]+$/;

// Korean phone: 010-XXXX-XXXX or 02-XXX-XXXX
const phoneRegex = /^(010|011|016|017|018|019)-\d{3,4}-\d{4}$/;

// Password strength: 8+ chars, 1 uppercase, 1 digit
const strongPw = /^(?=.*[A-Z])(?=.*\d).{8,}$/;

Key Points
  • /^pattern$/ anchors — ^ (start) and $ (end) guarantee the full string matches, preventing partial matches.
  • \d{9} matches exactly nine numeric digits (0–9).
  • regex.test(string) returns a fast, clean boolean (true / false).
  • In the HTML pattern="..." attribute, write regex WITHOUT leading/trailing slashes / /; in JavaScript code, enclose inside /pattern/.
