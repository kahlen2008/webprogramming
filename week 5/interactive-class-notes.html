1. The Page Skeleton

    <title>Page Title</title>
  </head>

6. CSS Selectors, Colors & Typography

CSS controls element color, size, spacing, fonts, and layout. Target elements via element tag (p), class (.card), or unique ID (#header).

Page 7 Selectors
CSS 
/* Element selector — affects ALL tags */
p { color: navy; }

/* Class selector — use class="card" in HTML */
.card {
  background: #f0f0f0;
  border-radius: 8px;
}

/* ID selector — use id="header" in HTML (only one element) */
#header { font-size: 32px; }

/* Colors and fonts */
body {
  background-color: #ffffff;
  color: #1a1a1a;
  font-family: 'Segoe UI', Arial, sans-serif;
  font-size: 16px;
  line-height: 1.6;
}
h1 { color: #1a56db; } /* blue heading */
a { color: #16a34a; }  /* green links */

7. Spacing: Margin and Padding (The Box Model)

Page 8: Margin is outside the border. Padding is inside between the border and content. Border separates them.

Page 8 Diagram
Box Model CSS 
.card {
  margin: 20px;        /* space OUTSIDE the element */
  padding: 16px;       /* space INSIDE the element */
  border: 1px solid #ccc;
  border-radius: 8px; /* rounded corners */
  box-shadow: 0 2px 8px rgba(0,0,0,0.1);
}

8. Flexbox Layout & Responsive Design

Page 8–9: Flexbox is the most useful modern layout tool. The parent controls arrangement, while children control space allocation.

Flexbox + Media Queries
Flexbox CSS 
/* Parent: controls HOW children are arranged */
.container {
  display: flex;
  gap: 16px;
  flex-wrap: wrap;
  justify-content: center;
  align-items: center;
}

/* Child: controls HOW MUCH space each child takes */
.card {
  flex: 1;
  min-width: 200px;
}

/* Responsive design (mobile-friendly) */
@media (max-width: 600px) {
  .container { flex-direction: column; }
}

14. A Complete Mini-App: Counter

Page 11–12: A complete interactive application putting HTML structure, CSS styling, and JavaScript logic together.

Page 11–12 Mini-App
Complete Counter HTML + JS 
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <title>Counter</title>
</head>
<body>
  <h2>Counter: <span id="count">0</span></h2>
  <button onclick="change(1)">+ Add</button>
  <button onclick="change(-1)">- Subtract</button>
  <button onclick="reset()">Reset</button>

  <script>
    let count = 0;
    function change(amount) {
      count = count + amount;
      document.getElementById('count').textContent = count;
    }
    function reset() {
      count = 0;
      document.getElementById('count').textContent = 0;
    }
  </script>
</body>
</html>
